Контекст: Мы пишем Discord-бота на Python, используя библиотеку discord.py.Твои правила:



Используй Cogs: Весь функционал должен быть разбит по классам (когам) для удобного управления модулями.

Асинхронность: Весь код должен быть строго асинхронным (async/await).

Slash-команды: Приоритет отдаем современным слэш-командам (app_commands), так как Discord уходит от старых префиксов.

Обработка ошибок: Всегда добавляй блок on_error или локальные обработчики для команд, чтобы бот не «падал» молча.

Типизация: По возможности используй аннотации типов (Type Hinting) для чистоты кода.
